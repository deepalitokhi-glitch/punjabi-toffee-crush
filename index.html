Punjabi Toffee Crush - Best Match 3 Game for Kids

Punjabi Toffee Crush is a fun, free and educational puzzle game specially made for Punjabi kids and families. This game combines colorful toffee crushing with learning Punjabi language. Many Punjabi families living in Canada, USA, UK want their kids to learn Punjabi alphabets, so we made this game with love for Punjabi culture.

What is inside this game?

This game has 6 exciting levels. Level 1 Toffee Crush is classic match 3 puzzle where you match 3 same toffees. Level 2 Ura Aira Bubble Game where Punjabi letters like ੳ, ਅ, ੲ, ਸ, ਹ fall from top like bubbles, you have to pop only correct letters. Level 3 Ka Kha Ga Learning where you learn ਕ ਖ ਗ by matching. Level 4 is Punjabi numbers ੧ ੨ ੩ learning. Level 5 is Shabad making. Final Boss is combination of all levels. All levels are safe, no personal data collection, best for kids age 3 to 10 years. Game works on mobile and computer both, no download needed.

How to Play?

Just click on Level 1 button to start. Tap on 3 same toffees to crush them. Complete 9 targets to unlock next level. In bubble game, quickly click on correct Punjabi letter before it falls. This lock system helps kids play step by step and learn properly. This website is made with love for Punjabi culture. We will add more games like Punjabi stories and rhymes soon. Enjoy and share with family!
